## Statement
The team will build a clinician-facing search results page where each result is a card showing the matched (visually highlighted) passage and a clickable citation chip (source document title + page) that opens the original document scrolled to and highlighting that passage, with an explicit empty state (no fabricated summary) when a search returns nothing.
